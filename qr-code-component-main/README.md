# Frontend Mentor - QR Code Component

This is a solution to the **QR Code Component** challenge from [Frontend Mentor](https://www.frontendmentor.io/).

## 📌 Overview

The goal of this project is to build a simple and responsive QR code component based on the design provided by Frontend Mentor.

The component contains:

* A QR code image
* A heading
* A short description
* A centered card layout
* Responsive design for different screen sizes

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox

## ✨ Features

* Responsive layout
* Centered QR code card
* Rounded corners
* Clean and simple UI
* Hover effect on the description text
* Mobile-friendly design
